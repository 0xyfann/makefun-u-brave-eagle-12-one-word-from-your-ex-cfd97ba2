Write a Python program (stdlib only), main.py, for the make.fun competition
"One Word From Your Ex". The program must write exactly ONE word to
/output/entry.txt (respecting the MAKEFUN_OUTPUT_DIR environment variable):
the single word an ex would use to describe the entrant, and nothing else.

Gate: the file must be UTF-8 text of 1 to 24 characters, not only white
space. Judge criteria, in order: exactly one real word an ex might say about
a former partner; makes the judge laugh out loud through surprise or a sharp
turn; stings with recognition because it is painfully true; lands instantly
with no explanation and no replaceable synonym; feels relatable. A word that
stings because it is true beats a word that only insults.

Pick an original single English adjective that is funny through painful
honesty rather than meanness. Keep the program minimal and deterministic,
and add a self-check that enforces the gate (one word, 1-24 characters)
before writing the file.
